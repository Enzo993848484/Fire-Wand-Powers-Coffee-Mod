# 🔥🪄☕ Fire Wand Powers + Coffee Mod

Projeto experimental de mod para **Minecraft Java 26.3 + Fabric**.

## Objetivo do mod
- Varinha de Fogo: clique direito, R (rajada), G (explosão), V (chuva), X (super fogo), sem destruir construções.
- Garrafa de café com duas cores, quatro porções e reabastecimento.
- Copo vazio e cheio, colocável no chão, que pode ser enchido e bebido.
- Preparação de café com grãos e água; efeitos e sons.

## Estado atual — NÃO JOGÁVEL
Este repositório contém **somente a estrutura Gradle/Fabric e uma classe Java inicial**. Ainda **não** contém a implementação completa dos itens, poderes, interações, receitas ou texturas. A compilação não foi validada. Não publique o resultado como um mod funcional.

## Compilação experimental
O GitHub Actions tem o workflow `Build Fabric mod`, configurado para Java 25 e Gradle. Abra a aba **Actions** para ver o resultado da compilação. Mesmo que gere um `.jar`, ele **não será um mod completo** até que os recursos acima sejam implementados e testados.
